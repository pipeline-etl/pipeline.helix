# Pipeline.RequestsSource

Pipeline.RequestsSource is an HTTP/HTTPS pipeline source for retrieving data from HTTP endpoints.

Installation
------------

* Install Pipeline.RequestsSource with Composer or with your own installer.
* Pipeline.RequestsSource follows the [semantic versioning][2] standards.

Community
---------

* Follow us on [GitHub][3].

Contributing
------------

Pipeline.RequestsSource is an Open Source, community-driven project. Join by contributing code or documentation.

If you encounter any issues when using Pipeline.RequestsSource you can report them [on github][4]
